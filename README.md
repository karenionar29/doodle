# 🎮 遊戲間

全家一起玩的網頁遊戲庫。**打開就能玩：零下載、零安裝；AI 在裝置裡跑，畫面和聲音不外傳。**

- ▶️ **開始玩：** https://karenionar29.github.io/doodle/
- 📤 **上傳檔案：** https://github.com/karenionar29/doodle/upload/main
- 🎯 **目標 1000 款；現在 45 款（G01～G45）。** 下一款是 G46。

> 離線：目標是離線可玩，但目前沒有離線快取（service worker）；AI 遊戲第一次要上網下載模型。斷網能不能玩還沒實測。

---

## 怎麼玩

1. 用手機、平板或電腦打開上面的「開始玩」網址。
2. 選「今天誰在玩」。
3. 從遊戲清單挑一款。

**建議加到主畫面**，開起來是全螢幕、沒有網址列，跟 App 一樣：
- iPhone／iPad（Safari）：分享 → 加入主畫面。**要從手機桌面的新圖示打開才是全螢幕**，在 Safari 裡開一定有網址列。
- Android（Chrome）：右上角 ⋮ 選單 → 加到主畫面（大廳有教學，還沒在真機測過）。

## 大廳（index.html）有什麼

入場門（先選誰在玩）、搜尋／篩選／排序（可只看「💻 電腦也能玩」）、我的最愛、隨機挑一款、口味分析、QR 分享、評分（六維 × 5 星＋最愛標籤＋一句話）、「📋 複製評分」、備份與還原、設定與搬家、版本列與「↻ 一鍵更新」。

評分和玩家設定只存在**這台裝置的瀏覽器**裡，別台看不到，Claude 也看不到 → 要分析時按「📋 複製評分」，貼進 Claude 對話。

## 試作 → 畢業（新遊戲和舊遊戲大修都這樣走）

1. **試作**：先做成 Claude 網頁版（artifact），在對話裡邊玩邊改，網址不變，不用一直上傳。這時下面「每款都要有」可以先不照。
2. **畢業**：Kris 說「畢業」才搬上 GitHub。Claude 把它改成完整版（照「每款都要有」8 條），再照「新增一款遊戲」改大廳，Kris 一次上傳。
3. **同一時間只有一個正本**：試作期間是 Claude 網頁版；畢業後是 GitHub 版，網頁版不再更新。
4. **舊遊戲大修**：先複製成 Claude 網頁版改到畢業，再傳回原本那個 `gNN-英文名.html`（大廳只要升 `APP_VERSION`、加 `CHANGELOG`）。

## 新增一款遊戲（畢業後）

1. 做一個新檔：`gNN-英文名.html`（NN 接著最大號往下排）。
2. 改 `index.html` 四個地方：
   - `GAMES` 陣列最後加一行：
     ```js
     { id:'g46', file:'g46-xxx.html', icon:'🎲', name:'遊戲名',
       desc:'一句話講怎麼玩。', tag:'2人+', cats:['動腦','對戰'], dev:'all' },
     ```
     - `dev`：`all`＝三種裝置都能玩、`cam`＝要鏡頭、`mic`＝要麥克風、`tilt`＝要傾斜感測。
     - `cats` 只能從 `CATS` 清單挑（AI、畫畫、鏡頭、聲音、體感、合作、動作、對戰、派對、動腦），寫別的字篩選會找不到。
   - `NEXT_NO` 改成下一號（例：`'G47'`）。
   - `APP_VERSION` 加 1。**沒加，舊裝置不會跳「一鍵更新」，就看不到新遊戲。**
   - `CHANGELOG` 最上面加一筆更新紀錄。
3. 照下面「交檔流程」上傳：新遊戲檔、`index.html`，分兩次傳。

## 每款遊戲都要有

1. **玩家不寫死**：載入 `family-players.js?v=5`，用 `FP.get()` 拿名單。依難度調整：
   - `FP.secs(p, 秒數)`：時間乘倍率（簡單 ×1.4、普通 ×1.0、困難 ×0.7）。
   - `FP.lv(p).loose`：判定寬鬆度（簡單 2、普通 1、困難 0）。
2. **縮放鎖**：載入 family-players.js 就自動生效（小孩兩指誤觸不會把畫面放大縮小弄跑）。
3. `apple-mobile-web-app-capable` meta（加到主畫面才會全螢幕）。
4. 頂部中央「← 離開」膠囊，連到 `index.html#lobby`（回大廳、跳過入場門）。
5. **畫畫類標配**：13 色調色盤、三種筆刷粗細、🧽 橡皮擦、↩️ 復原（記下每一筆、重播出來的架構）。
6. **音效用 Web Audio 程式合成**，零音檔。
7. **AI 推論一律放 Web Worker**（另開一個小幫手跑，畫面不卡）。
8. **CONFIG 物件**集中所有可調的數字。

### AI 畫畫遊戲的兩個細節（G01、G05、G14 用的 QuickDraw 塗鴉模型）
- **黑底白線**：AI 畫布保持透明、從 alpha 通道取筆跡，再用邊界框裁切放大，模型才認得。
- **題庫防呆**：啟動時把題庫和「模型真的認得的標籤」取交集，寫錯的題目自動剔除。

## 交檔流程（只有手機也能做）

1. 從 Claude 下載檔案 → 存到「檔案」App。
2. 開上傳網址 → **一次傳一個檔** → Commit changes。
3. 等 1 分鐘 → 開遊玩網址，**後面加 `?v=數字` 破快取**（例：`.../g46-xxx.html?v=1`；這個數字隨便換一個沒用過的就好）。

## 改共用 JS（family-players.js）

程式裡載入共用 JS 的 `?v=5` 是**全站統一的破快取號碼**（叫瀏覽器重抓新檔的暗號），不是檔案版本；family-players.js 檔頭自己寫的是 v2。

改完共用 JS，**46 個檔（45 款遊戲＋index.html）的 `?v=5` 要一起升成 `?v=6`**，不然瀏覽器會拿到舊的。

## 常見坑（別再踩）

- **iPhone 全螢幕被踢回 Safari**：從主畫面圖示開啟時，大廳用一般連結跳到別的檔，iOS 會跳回 Safari、冒出網址列。解法已上線：遊戲卡片有 `data-game` 屬性，`isStandalone()` 為真時用 `e.preventDefault()` ＋ `location.href` 換頁。**改大廳時絕不能弄壞這段。**
- **Claude App 的預覽視窗測不了**（沒網路、找不到隔壁檔案）→ 一定傳上 GitHub 用真網址測。
- **開起來是舊的** → 快取，網址加 `?v=數字`；大廳出現「一鍵更新」就按。
- **404** → 檔案沒傳上去，去 repo 檔案清單檢查。
- **共用 JS 改版** → 所有 HTML 的 `?v=` 一起升。
